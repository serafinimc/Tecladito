# Tecladito

Una experiencia web segura y divertida para que los chicos descubran el teclado sin activar accidentalmente teclas o atajos especiales.

## Funciones

- Modos para preescolar, primeras palabras y escritura libre.
- Protección de teclas especiales mediante pulsación prolongada.
- Configuración de mayúsculas, permanencia de letras y sonido.
- Área de adultos protegida por una pulsación de tres segundos.
- Experiencia adaptable a pantalla completa.

## Desarrollo

```bash
npm install
npm run dev
```

## Verificación

```bash
npm run lint
npm run build
```
